# Jupyter privacy notice (this Lab)

The file browser hides other people's **private** project folders in this space.

That hide is **visual only**. The kernel and terminal can still see every path
that is mounted in this Lab. Do not treat JupyterLab as a security boundary
inside your group (project or community).

Isolation **between** the project Lab and the community Lab is real: those
are separate containers with separate host directories.
